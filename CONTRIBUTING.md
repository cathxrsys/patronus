# Contributing

English

Thank you for your interest in improving Patronus.

At the current stage of the project, we accept pull requests mainly for:

1. Performance improvements.
2. Bug fixes.
3. Stability improvements.
4. Security hardening.
5. Build, tooling, CI, and packaging fixes.
6. Documentation improvements that stay consistent with the current project direction.

Please do not open pull requests that introduce new major features, new product concepts, new protocol directions, or broad architectural shifts without prior discussion with the project developers.

New features and new concepts are discussed personally with the project developers first.

Contribution rules:

1. Keep changes focused and minimal.
2. Avoid unrelated refactoring in the same pull request.
3. Explain the problem, the solution, and any tradeoffs clearly.
4. If the change affects security, protocol behavior, storage, networking, or update logic, describe that explicitly.
5. By submitting a contribution, you agree that the maintainers may review, edit, reject, or merge it into the official repository.

Russian

Спасибо за интерес к развитию Patronus.

На текущем этапе проекта мы в основном принимаем pull request только на темы:

1. Повышения производительности.
2. Исправления багов.
3. Повышения стабильности.
4. Усиления безопасности.
5. Исправлений, связанных со сборкой, tooling, CI и packaging.
6. Улучшений документации, если они не противоречат текущему направлению проекта.

Пожалуйста, не открывайте pull request с новыми крупными функциями, новыми продуктовыми концептами, новыми направлениями протокола или широкими архитектурными изменениями без предварительного обсуждения с разработчиками проекта.

Новые функции и новые концепты обсуждаются лично с разработчиками проекта.

Правила контрибьютинга:

1. Делайте изменения точечными и минимальными.
2. Не смешивайте в одном pull request несвязанный рефакторинг.
3. Чётко описывайте проблему, решение и компромиссы.
4. Если изменение затрагивает безопасность, поведение протокола, хранилище, сеть или логику обновлений, указывайте это явно.
5. Отправляя вклад, вы соглашаетесь с тем, что сопровождающие проекта могут проверить, изменить, отклонить или включить его в официальный репозиторий.
